# rtgadd
Selamat Datang!
RTGAdd adalah aplikasi berbasis web yang dirancang untuk memadukan RTG dan pengembangan dasbor untuk memudahkan pemerintah pusat dan daerah dalam melakukan perencanaan dan pengawasan kebutuhan guru di satuan pendidiakn berbasis data. RTGAdd akan diujicobakanp penggunaannya di lima kabupaten/kota, yaitu: Kabupaten Karo - Sumatera Utara, Kota Dumai - Riau, Kabupaten Muoaro Jambi - Jambi, Kota Semarang - Jawa Tengah, dan Kabupaten Kutai Kartanegara - Kalimantan Timur

## Spesifikasi
- Arsitektur Aplikasi  
  - Tipe 		: Web-based Application (Client–Server) 
  - Browser     : Chrome, Firefox, Edge, Safari
  - Pengguna    : Nasional, Provinsi, Kab/Kota
- Frontend (User Interface) 
  - Pemrograman	        : HTML5, CSS3, JavaScript 
  - CSS Framework       : Bootstrap 5
  - Visualisasi Data	: ApexCharts
- Backend (Server) 
  - DBMS		    : MySQL 9.1.0 
  - Pemrograman 	: PHP 8.0.30 
  - Library		    : Jquery 3.7.1 
  - Web Server	    : Apache 2.4.x
